JsonParser 需求文档

1. 项目概述
   JsonParser 是一个轻量级的、基于模板的 JSON 路径解析库，旨在以零开销抽象的方式为 C++ 开发者提供统一、高效、类型安全的 JSON 数据访问接口。它不依赖任何特定的 JSON 实现，而是通过适配器模式支持多种主流 JSON 库，实现“一次编写，随处运行”的解析体验。

2. 设计目标
- 零开销抽象：所有类型转换、路径解析策略均在编译期完成，无虚函数、无 std::function 类型擦除，性能与手写专用解析代码相当。
- 开箱即用：预置对 nlohmann/json、rapidjson、boost::json 等主流库的适配，用户仅需包含头文件并选择库即可使用。
- 链式调用：支持通过连续 parse() 方法一次性提取多个字段，减少临时变量和嵌套检查。
- 类型安全：通过模板参数指定期望类型，编译期检查类型兼容性，避免运行时类型错误。
- 灵活错误处理：提供 Required/Optional 两种存在性策略，并支持用户自定义错误回调。
- 扩展性：通过 JsonTraits 特化机制，用户可轻松适配自有或第三方 JSON 类型。

3. 功能需求

3.1 路径解析
- 支持以点号分隔的路径访问嵌套对象，如 "a.b.c"。
- 支持数组索引访问，如 "a[0].b"，索引为非负整数。
- 路径字符串为 std::string_view，支持运行时动态构造。
- 当路径不存在时，根据策略（Required/Optional）决定是否抛出异常或静默忽略。

3.2 类型提取
- 提供一组预定义提取器（Extractor），支持常见数据类型：
    - JsonInt -> int
    - JsonDouble -> double
    - JsonString -> std::string
    - JsonBool -> bool
    - JsonArray -> std::vector<JsonType>（递归存储 JSON 节点）
    - JsonObject -> 自定义对象映射（可选）
- 提取器通过编译期特化实现，可针对不同 JSON 库适配内部 API。
- 允许用户自定义提取器（通过特化 Extractor<JsonType, T>）。

3.3 解析接口

模板类 JsonParser<JsonType> 提供以下公共成员：

explicit JsonParser(const JsonType& root);

template <template <typename> class ExtractorT,
typename ExistencePolicy,
typename Func>
JsonParser& parse(std::string_view path, Func&& callback);

参数说明：
- ExtractorT：一个模板，接受 JsonType 并特化为具体的提取器（如 JsonInt）。
- ExistencePolicy：Required 或 Optional。
- callback：可调用对象，接受提取后的值（类型由 ExtractorT::value_type 决定）。
  返回值：JsonParser& 以支持链式调用。

3.4 错误处理
- 缺失处理：
    - Required：路径不存在时抛出 std::runtime_error（可配置为调用错误回调）。
    - Optional：路径不存在时静默返回，不执行回调。
- 类型不匹配：当提取器无法从 JSON 节点转换为目标类型时，抛出异常（或通过错误回调通知）。
- 用户可通过编译期开关启用异常或自定义错误处理函数。

3.5 回调支持
- 回调可以是任何可调用对象（函数指针、lambda、std::bind 表达式、函数对象等）。
- 特别支持成员函数绑定，允许在类内部处理解析结果（如 [this](int v){ this->onInt(v); }）。
- 回调参数类型与提取器返回值类型严格匹配，编译期检查。

4. 非功能需求

4.1 性能
- 所有模板化操作内联展开，无运行时多态开销。
- 路径解析采用高效的字符串查找，并支持缓存预解析路径（可选优化）。
- 内存分配仅在需要构造容器（如 std::vector<JsonType>）时发生，其余操作引用原始 JSON 数据。

4.2 可扩展性
- 支持新的 JSON 库只需特化 JsonTraits<JsonType>，无需修改库源码。
- 用户可自定义提取器，扩展新的数据类型。
- 错误策略可扩展（如 Default<T> 提供默认值）。

4.3 兼容性
- C++17 及以上标准（若需 constexpr 路径解析可升级至 C++20）。
- 无外部依赖（除目标 JSON 库）。
- 头文件库（Header-only），易于集成到构建系统。

4.4 线程安全
- JsonParser 对象本身是只读的（仅持有 const JsonType&），因此多个线程可并发调用 parse 而无需同步（前提是底层 JSON 数据本身不修改）。

5. 支持的 JSON 库（初始版本）

库名称             类型                              自动适配条件
nlohmann/json      nlohmann::json                    检测到 NLOHMANN_JSON_HPP 宏
rapidjson          rapidjson::Document / Value       检测到 RAPIDJSON_DOCUMENT_H_
boost::json        boost::json::value                检测到 BOOST_JSON_VALUE_HPP
simdjson           simdjson::dom::element            用户自定义（默认不自动）

6. 使用示例

6.1 基本用法
#include <nlohmann/json.hpp>
#include "json_parser.hpp"

nlohmann::json json = R"({"a":{"b":42}})"_json;
JsonParser<nlohmann::json> parser(json);

parser.parse<JsonInt, Required>("a.b", [](int val) {
std::cout << val << std::endl;
});

6.2 数组与嵌套解析
json = R"({"list":[1,2,3]})"_json;
parser.parse<JsonArray, Required>("list", [](const std::vector<nlohmann::json>& arr) {
for (const auto& elem : arr) {
JsonParser<nlohmann::json> sub(elem);
sub.parse<JsonInt, Required>("", [](int v){ std::cout << v; });
}
});

6.3 绑定成员函数
class Handler {
public:
void onInt(int v) { ... }
void process(const nlohmann::json& j) {
JsonParser<nlohmann::json> parser(j);
parser.parse<JsonInt, Required>("a.b", [this](int v) { onInt(v); });
// 或 std::bind(&Handler::onInt, this, std::placeholders::_1)
}
};

6.4 数组索引
parser.parse<JsonInt, Required>("a[0].b", [](int v){ ... });

7. 实现约束
- 必须通过 JsonTraits<JsonType> 提供以下静态方法（最小接口），命名遵循谷歌规范（小驼峰）：
    - isObject, isArray, isNumberInteger, isString, isBool
    - hasKey, getChild, getArraySize, getArrayElement
    - getInt, getDouble, getString, getBool（或由提取器直接调用库 API）
- 提取器 Extractor<JsonType, T> 必须提供：
    - using value_type = T;
    - static bool extract(const JsonType&, T& out);
- 默认错误处理：Required 缺失或类型不匹配时抛出 std::runtime_error，可选策略可覆盖。

8. 扩展指南

8.1 适配新 JSON 库
#include "json_parser.hpp"
#include "my_json.hpp"

template <>
struct JsonTraits<my::Json> {
using Json = my::Json;
static bool isObject(const Json& j) { return j.isObject(); }
// ... 实现所有必需接口，命名小驼峰
};

8.2 自定义提取器
template <>
struct Extractor<my::Json, MyType> {
using value_type = MyType;
static bool extract(const my::Json& j, MyType& out) {
// 自定义转换
}
};

9. 未来扩展（可选）
- 支持编译期路径校验（C++20 consteval）。
- 支持 JSON 模式（Schema）验证。
- 支持异步解析（与协程集成）。
