2. JsonScope
基于RAII机制的Json域，避免频繁获取重复的路径
JsonParser(json) parser;
{
    JsonScope scope(parser, "a.b"_path);
    // 从a.b.c获取整数
    std::cout << parser.Acquire<JsonInt, Required>("c"_path) << std::endl;
} //scope析构后，parser的root路径自动回退
